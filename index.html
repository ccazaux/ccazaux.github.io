Bienvenue dans vos cours

Choisissez une matière dans l’arborescence à gauche. Vous pourrez consulter les cours, lancer les démonstrations interactives et ouvrir ou télécharger les documents PDF et texte.

Comment naviguer ?

Cliquez sur un dossier pour déplier son contenu. Les fichiers PDF et texte s’affichent directement dans la page ; le bouton Télécharger permet d’enregistrer une copie. Le bouton ☰ Menu en haut à gauche masque ou affiche l’arborescence.

Les dossiers et fichiers du dépôt sont détectés automatiquement. Ajoutez simplement vos documents dans GitHub : ils apparaîtront ici après actualisation du site.
