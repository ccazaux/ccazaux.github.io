# Chapitre 1 — Numération

## 1. Objectifs

À la fin de ce chapitre, vous devez savoir :

- distinguer les bases de numération ;
- convertir un nombre décimal en binaire ;
- convertir un nombre binaire en décimal.

## 2. Principe

Un système de numération positionnel utilise une base. En base 10, les chiffres possibles vont de 0 à 9. En base 2, seuls les chiffres 0 et 1 sont utilisés.

## 3. Exemple de conversion

Le nombre binaire `1011₂` vaut :

\[
1\times 2^3 + 0\times 2^2 + 1\times 2^1 + 1\times 2^0 = 11
\]

Donc `1011₂ = 11₁₀`.
